# CS 465 Full Stack Web Application

This repository contains my completed full stack web application for **CS 465: Full Stack Development** at Southern New Hampshire University. The application supports both customer-facing and administrative functionality and includes secure authentication features for protected administrative access.

The final iteration of this project focused on improving security, usability, and maintainability while demonstrating full stack development principles.

---

## Application Architecture

### Frontend Development

This project uses multiple frontend approaches, including Express-rendered HTML, JavaScript-driven functionality, and single-page application (SPA) concepts. Express HTML was useful for server-side rendering and routing, while JavaScript enabled dynamic user interactions and asynchronous data handling. SPA components allowed for smoother user experiences by reducing page reloads and improving responsiveness. Each approach served a specific purpose, and together they created a flexible and user-friendly interface.

### Backend and Database

The backend uses **Node.js with Express** and a **MongoDB NoSQL database**. MongoDB was selected because of its flexibility and schema-less design, which made it well-suited for handling JSON-based data and evolving application requirements. This allowed the backend to easily store and retrieve data without requiring rigid table structures, supporting faster development and easier changes over time.

---

## Application Functionality

### JSON and Full Stack Integration

JSON differs from JavaScript in that it is a lightweight data interchange format rather than a programming language. JSON serves as the bridge between the frontend and backend by providing a consistent structure for sending and receiving data through API endpoints. In this project, JSON was used to transfer user input, authentication data, and database results between the client and server, enabling seamless communication across the application layers.

### Code Refactoring and Reusable Components

Throughout development, I refactored code to improve efficiency and maintainability. This included separating concerns between routes, controllers, and services, as well as creating reusable UI components for forms and navigation elements. Reusable components reduced duplication, simplified updates, and improved consistency across the application, making the system easier to maintain and extend.

---

## Testing and Security

Testing API endpoints involved verifying request methods such as GET, POST, PUT, and DELETE to ensure proper data retrieval and submission. Securing administrative routes added complexity, as authentication and authorization layers needed to be tested alongside standard functionality. Implementing secure login authentication required validating credentials, protecting sensitive endpoints, and ensuring unauthorized users could not access administrative features. Understanding how endpoints, methods, and security layers interact is essential for building reliable full stack applications.
